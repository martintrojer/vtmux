The second release candidate of vtmux, the drop-in tmux 3.8 replacement: fixes only. Upgrade from rc1 or beta3 with no restart: `tmux vtmux-upgrade -b <new binary>`.

## Fixed

- **Server crashes.** None of these takes your sessions down any more:
  - `join-pane` or `move-pane` of a window's last pane, with `pane-scrollbars`, `focus-events` or `display-panes`;
  - `select-layout` with an odd v1 layout string (tmux 3.8 crashes there too);
  - a session destroyed while one of its clients closes;
  - a huge typed key or mouse report.
- **Live upgrade.** A very wide pane or an inconsistent snapshot refuses the upgrade and keeps the old server running. Running out of memory fails the one command instead of ending the server.
- **As in tmux.** `new-session -x`/`-y` over 10000 clamps the window. A tree-mode menu acts for the client that opened it. A suspended client stays attached when `kill-session` moves it. `respawn-window -k` clears a modal pane it destroys, as upstream tmux does.
- **Linked as `tmux`.** Meeting a real tmux server on tmux's socket, vtmux says so and exits, instead of hanging or reporting `server exited unexpectedly`.

Full list: [CHANGELOG.md](https://github.com/martintrojer/vtmux/blob/main/CHANGELOG.md).

## Install

`mise use -g github:martintrojer/vtmux` (mise waits a day before it offers a new release), the tarballs below, or `cargo install --locked vtmux@3.8.0-rc.2` (needs Zig 0.17).
