The third release candidate of vtmux, the drop-in tmux 3.8 replacement: two opt-in program protocols, and libghostty-vt 1.0.2. Upgrade from rc2, rc1 or beta3 with no restart: `tmux vtmux-upgrade -b <new binary>`.

## New

- **Program Status (OSC 7501).** `set -s vtmux-program-status on`: a program's status reports (idle, working, done, blocked, error) are recorded per pane and its `OSC 7501 ; ?` query is answered. `#{pane_program_state}`, `#{pane_program_kind}`, `#{pane_program_progress}`, `#{pane_program_app}`, `#{pane_program_title}` and `#{pane_program_message}` show the most urgent record; `#{window_program_state}` and `#{session_program_state}` roll the states up. The `vtmux-pane-program-status` hook runs on a change. Nothing goes to the outer terminal.
- **Program Resume (OSC 7577).** `set -s vtmux-program-resume on`: a non-empty pane started or respawned while on gets a fresh `OSC7577_TOKEN`, and a program reporting with a valid MAC is recorded: `#{pane_resume_command}`, `#{pane_resume_cwd}` and `#{pane_resume_pid}` show it. vtmux never relaunches anything.
- **Token hygiene.** An inherited `OSC7577_TOKEN` is removed from every pane and popup environment, and `update-environment` does not import it.
- **libghostty-vt 1.0.2.** The terminal engine moves to the 1.0.2 release.
- **Live upgrade.** Upgrade from rc2, rc1 or beta3 without restarting sessions; future upgrades between compatible builds keep OSC 7501/7577 grants, tokens and records.

Full list: [CHANGELOG.md](https://github.com/martintrojer/vtmux/blob/main/CHANGELOG.md).

## Install

`mise use -g github:martintrojer/vtmux` (mise waits a day before it offers a new release), the tarballs below, or `cargo install --locked vtmux@3.8.0-rc.3` (needs Zig 0.17).
