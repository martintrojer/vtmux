The second beta of vtmux, the drop-in tmux 3.8 replacement. Upgrade a running server with no restart: `tmux vtmux-upgrade -b <new binary>`.

## New

- **Kitty graphics (opt-in).** `set -s vtmux-graphics on`: images from `kitten icat`, chafa, image.nvim and plotting tools show in the pane, clip at its edges and follow zoom, scrolling and window switches. No `allow-passthrough` needed.
- **More terminals.** Most of ncurses 6.6's terminal database attaches (wezterm, contour, foot, rio and more), on hosts without terminfo for them.
- **Pixel sizes.** Panes report their size in pixels, so image tools size their output.

## Faster

| | before | now | tmux 3.8 |
|---|---|---|---|
| vim/less over 1M lines of history | 4.1 s | 3 ms | 3 ms |
| key echo | 0.38 ms | 0.30 ms | 0.24 ms |
| agent TUIs, server CPU vs tmux | up to 1.25x | 0.76-0.92x | 1x |

## Safer

- A full code review across the codebase found and fixed live-upgrade data losses (typed input, partly sent messages, queued commands), a crash after a re-attach with queued notifications, and a persistence case that could overwrite the only good checkpoint.
- Unfinished escape strings are capped at `input-buffer-size`, as in tmux.
- Memory-safety fixes in the bundled Ghostty bindings.

## Closer to tmux

Signals and terminal settings for clients and panes, the current target across command lists, target lookups, `#{V:}` loops, `#{pane_last_output_time}`, window names after a split, and a few dozen smaller fixes.

Full list: [CHANGELOG.md](https://github.com/martintrojer/vtmux/blob/main/CHANGELOG.md).

## Install

`mise use -g github:martintrojer/vtmux`, the tarballs below, or `cargo install --locked vtmux@3.8.0-beta.2` (needs Zig 0.17).
