The third beta of vtmux, the drop-in tmux 3.8 replacement. From beta2, upgrade with no restart: `tmux vtmux-upgrade -b <new binary>`.

## New

- **Restores you can pick up.** After a reboot, each restored pane shows its last screen. Press Enter and its command starts again below it, editor screens included. `set -s vtmux-persist-respawn auto` restarts your shells by itself; agents, editors and `ssh` wait for Enter.
- **A restart that fails keeps the screen.** If a restored pane's program is gone, the pane stays restored with its screen and says why, instead of closing.

## Safer

- `vtmux-upgrade -b` onto anything that is not a vtmux (`/bin/echo`, a script) is refused with exit 1 and the server keeps running. Before, it could replace the server and lose every session. Downgrades to beta1 and beta2 still work.
- Live upgrades keep keys, a held Esc, a paste in flight and a signal sent during the switch.
- `set -s vtmux-persist off` at run time now sticks across a restart.
- Two end-of-milestone review panels, 63 findings, every critical and high fixed and re-reviewed.

## Closer to tmux

Esc then a key on a busy server is M-x, `tmux` in a pane with no `TMUX_PANE` finds its pane by its tty, `break-pane -a/-b`, `copy-mode -S`, format comparisons on non-UTF-8 bytes, the no-`PATH` search path, and a detach during a flood no longer freezes the terminal.

Full list: [CHANGELOG.md](https://github.com/martintrojer/vtmux/blob/main/CHANGELOG.md).

## Install

`mise use -g github:martintrojer/vtmux`, the tarballs below, or `cargo install --locked vtmux@3.8.0-beta.3` (needs Zig 0.17).
