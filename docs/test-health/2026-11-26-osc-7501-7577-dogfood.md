# OSC 7501 / 7577 live dogfood, 2026-11-26

Task `dogfood_7577` of `osc75xx`. D34 (OSC 7501 program status) and D35 (OSC 7577 program resume) run in a live, isolated server built from HEAD `0ac3cd8c`, with real processes in the panes.

## Conditions

- Host: macOS arm64, `mise exec -- cargo build -p vtmux` (debug), `target/debug/vtmux`, `vtmux 3.8-rc2`.
- Binary SHA-256: `396c9307bcbd625d6a8b9bc4abf9acb888cd2320fa0942f9d1265b894e01bdac`. The live upgrade moved the server onto a byte-identical copy of it (same SHA).
- Safety: `unset TMUX`; private dir `/tmp/vtmux-dogfood-$$` as `TMUX_TMPDIR` and `-S /tmp/vtmux-dogfood-$$/sock` on every call; `trap ... kill-server; rm -rf` on EXIT. No leftover `/tmp/vtmux-dogfood-*` after the run; `mise exec -- cargo xtask sockets` exits 0.
- The server is started with `OSC7577_TOKEN=leaked-outer-token` in its environment. A client attaches through a pty (`client.py`, 120x40) so popups and focus work.

## Run

Stage the helper scripts from *Scripts* below into `/tmp/dfsrc` first (the driver sets `SRC=/tmp/dfsrc`), then run:

```
REPO=$PWD PIWAIT=15 BIN=$PWD/target/debug/vtmux bash dogfood.sh > run.log 2>&1
```

Result: exit 0, no timeouts. The *Output* section is `run.log`, edited only to replace the checkout path with `$REPO` and the temp dir with `$$`, and to elide pi's error screen. Full `show-environment -g` dumps are not recorded (they hold the host environment, API keys included); the script counts `OSC7577`/`leaked` lines instead.

### Notes and limits

- `pi` on `PATH` is a launcher that calls `sandbox-exec`; inside this task's sandbox it exits with status 71 (`sandbox_apply: Operation not permitted`), so the run uses `/usr/local/bin/pi_cli/pi.real`. The model call fails, so pi's bash tool never ran: the pi run proves the 7501 handshake and states, not token hygiene inside pi. A headless `pi -p` needs the same credentials and is no better a probe here.
- `pane_program_kind` shows `none` when a record has a state and no valid kind (`kind=input` is not one of `permission`, `question`, `auth`, so it too shows `none`).
- `#{I/e:OSC7577_TOKEN}` and `#{E:OSC7577_TOKEN}` were not checked against a positive control (an unknown modifier may print empty whatever the name), so they prove nothing alone. The pane-side `echo "[$OSC7577_TOKEN]"` and popup checks carry the hygiene result.
- The live upgrade keeps the server pid (`execve` in place), as designed.
- No defect found in D34 or D35.

`emit7577.py` (rev 0.5 emitter, run in the pane):

```python
#!/usr/bin/env python3
"""Rev 0.5 emitter. Runs in a pane; reads commands from a FIFO ($1), one per line:
  report <cwd|-> <argv0> [argv...]   signed argv report
  stale  <argv0> ...                 signed report, time 120 s old
  badmac <argv0> ...                 report with a wrong MAC
  old    <argv0> ...                 signed report, time older than the last accepted
  clear                              signed clear=1
  raw    <python-literal bytes>      write bytes verbatim to the tty
  quit"""
import base64, hashlib, os, shlex, sys, time
tok = os.environ.get("OSC7577_TOKEN", "")
tty = os.open("/dev/tty", os.O_WRONLY)
b64 = lambda s: base64.b64encode(s.encode()).decode()
def emit(prefix, tok=tok):
    mac = hashlib.sha256((prefix + ":" + tok).encode()).hexdigest()
    os.write(tty, f"\x1b]7577;{prefix}:mac={mac}\x1b\\".encode())
def argv_prefix(cwd, argv, t):
    p = f"pid={os.getpid()}:time={int(t)}:argv={','.join(b64(a) for a in argv)}"
    return p + (f":cwd={b64(cwd)}" if cwd != "-" else "")
print("emitter pid", os.getpid(), "token", tok, "len", len(tok), flush=True)
while True:
    with open(sys.argv[1]) as f:
        for line in f:
            w = shlex.split(line)
            if not w: continue
            c = w[0]
            if c == "report": emit(argv_prefix(w[1], w[2:], time.time()))
            elif c == "stale": emit(argv_prefix("-", w[1:], time.time() - 120))
            elif c == "old": emit(argv_prefix("-", w[1:], time.time() - 30))
            elif c == "badmac": emit(argv_prefix("-", w[1:], time.time()), tok="wrong")
            elif c == "clear": emit(f"pid={os.getpid()}:time={int(time.time())}:clear=1")
            elif c == "raw": os.write(tty, eval(line.split(None, 1)[1]))
            elif c == "quit": sys.exit(0)
```

`query7501.py`:

```python
import os, sys, termios, tty, select
fd = os.open("/dev/tty", os.O_RDWR); old = termios.tcgetattr(fd); tty.setraw(fd)
os.write(fd, b"\x1b]7501;?\x1b\\")
buf = b""
while select.select([fd], [], [], 1.0)[0]:
    buf += os.read(fd, 256)
    if buf.endswith((b"\x07", b"\x1b\\")): break
termios.tcsetattr(fd, termios.TCSADRAIN, old)
open(sys.argv[1], "w").write(repr(buf) + "\n")
```

`client.py` (attaches a client through a pty):

```python
import os, pty, sys, fcntl, termios, struct, time
vt, sock, sess = sys.argv[1:4]
pid, fd = pty.fork()
if pid == 0: os.execv(vt, [vt, "-S", sock, "attach", "-t", sess])
fcntl.ioctl(fd, termios.TIOCSWINSZ, struct.pack("HHHH", 40, 120, 0, 0))
while True:
    try:
        if not os.read(fd, 65536): break
    except OSError: break
```
