# The costs at 3.8-rc1 (2026-11-13)

The README's *What it costs* numbers, measured again on the rc1 release build before announcing it.

## Conditions

- Commit `261a31f8` (tag `v3.8-rc1`), `cargo build --release` (fat LTO, stripped), libghostty-vt 1.0.1 from the signed release tarballs.
- Reference tmux 3.8 from `cargo xtask ref-tmux`, stripped with `strip` for the size row.
- dev1: Linux 6.16, AMD EPYC Genoa, 96 CPUs, load 1.8-3.0, shared with nothing else of ours.
- `RUNS=3 mise exec -- python3 scripts/bench.py idle scale key_echo`, median of 3.

## Results

| | tmux 3.8 | vtmux 3.8-rc1 | vtmux / tmux |
|---|---|---|---|
| Idle server (1 session, 60 s, `-f /dev/null`), RSS | 4.2 MB | 8.5 MB | 2.0x |
| 400 idle panes (10 sessions x 10 windows x 4 `cat`), RSS | 6.2 MB | 16.3 MB | 2.6x |
| Each idle pane | 5.3 KB | 20.1 KB | 3.8x |
| Creating the 400 panes, CPU | 140 ms | 230 ms | 1.6x |
| Key echo p50 / p90, other pane idle | 0.21 / 0.27 ms | 0.30 / 0.37 ms | 1.4x |
| Key echo p50 / p90, next to a `yes` flood | 0.57 / 0.83 ms | 0.31 / 0.46 ms | 0.54x |
| Release binary, stripped | 1.27 MB | 10.39 MB | 8.2x |

Idle CPU and wakeups were 0 for both. No key was lost in any run.
